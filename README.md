# Smash Rankings

An unofficial fan site for Super Smash Bros. Ultimate player rankings.

Rankings come from tournament results on [start.gg](https://www.start.gg/). Anywhere that data appears, the site will say **Data from start.gg** and keep start.gg's links. This is not an official Nintendo or start.gg product.

The first version is a website. The same project is meant to become an iPhone and Android app later, without starting over.
